# CMCC 好友麻将

面向手机浏览器的四人联机麻将项目。当前已完成 H5 联机大厅、私有手牌、横屏四方牌桌，过、吃、碰、普通杠、自摸、点炮胡、抢杠胡，中发白/东南西北特殊杠、连续涨毛，胡牌与杠分结算，下一局和庄家轮转，8/16局整场模式，提前结算投票、逐局记录，以及适合手机实玩的动作反馈、基础音效、正式结算和弱网重连界面。

## 当前进度

- 六位房间号、四人座位、准备状态和实时同步。
- 刷新或短暂掉线后恢复原座位。
- 房主可一键补齐测试玩家并开始测试对局。
- 已接入最小牌局模型：136张牌、洗牌、随机庄家、四人发牌和牌张守恒校验。
- 对局页面已重做为横屏四方桌：仓库原始牌桌背景、真实麻将牌图集、四家座位、牌墙、分区弃牌、中央风位/余牌计数和当前行动高亮。
- 每名玩家只会收到自己的具体手牌，其他玩家仅公开手牌数量；刷新和断线重连可恢复同一副牌。
- 服务端为弃牌计算私有响应候选：吃仅限下家，碰/明杠/胡可响应任意一家；所有候选真人响应后按胡 > 杠 > 碰 > 吃裁决，并支持一炮多响的赢家集合。
- 已实现过、吃、碰和明杠落地；吃碰后直接出牌，明杠从牌墙尾部补牌，公开副露会显示在对应玩家座位旁。
- 已实现普通胡和七小对结构校验，包括三门齐全、一九面子/对子、刻子及杠豁免；点炮胡后公开赢家、点炮者和胡牌张并结束本局。
- 当前玩家会收到私有的自摸、暗杠和加杠候选；暗杠直接从牌墙尾部补牌，加杠先开启抢杠胡窗口，全过后才升级原碰牌并补牌。
- 已支持抢杠胡和一炮多响式的多人抢杠；被抢后原碰牌保持不变，结算公开赢家、加杠者与被抢牌张。
- 已实现中发白、东南西北两类特殊杠及逐张连续涨毛；首次特殊杠和每一次涨毛都独立开放抢杠窗口，全过后分别杠尾补牌。
- 普通暗杠的具体牌面只对本人可见，公共快照和其他玩家界面仅显示四张牌背。
- 已接入服务端权威计分：每人初始200分，支持点炮、自摸、一炮多响，庄家/闭门/碰碰胡/七小对/三不烙叠倍，以及明杠、暗杠、加杠、特殊杠和涨毛固定分；牌桌显示累计分，本局结束显示支付明细。
- 本局结束后房主可直接开始下一局；庄家胡牌或流局连庄，庄家未胡则由下家坐庄，累计总分跨局保留。
- 创建房间可选择固定8局或16局；达到局数上限或局末出现负分时整场结束，并按累计分生成支持并列名次的最终排名。
- 每局结算后任意玩家可申请提前结算；申请人视为同意，另外三人全部同意后立即生成整场排名，任一人拒绝则可继续下一局。投票和逐局记录支持断线重连恢复，测试玩家会自动同意以方便单人联调。
- 可用版牌桌会依次提示公开出牌、吃碰杠胡、轮到本人和局末结果，并配有可关闭的基础合成音效、震动提示、摸牌/出牌动画、四人结算榜、邀请链接、分享战绩和“再开一桌”。
- 客户端具备操作防重复、20秒心跳、45秒失联判定、指数退避重连、手动重试和断线遮罩；服务端提供 `/healthz` 用于确认实例与模型版本。
- 单人联调时三名测试玩家会自动摸打，真人每出一张即可跑完一整圈并重新获得14张手牌。
- 候选计算、玩家响应、裁决结果、副露、回合推进、私有手牌恢复和异常请求均写入结构化监控日志，不记录具体私有手牌或未选择的候选内容。
- 服务端使用 TypeScript 和 WebSocket，客户端使用移动端 H5。
- 已整理幼麟四川麻将的牌桌背景、麻将牌和牌桌操作图集。
- 最新麻将规则源文件位于 `docs/GAME_RULES.md`，可直接在 GitHub 查看和比对；Word 固化稿位于 `deliverables/`。

## 回家后继续开发

```powershell
git clone https://github.com/lzy271713290/CMCCmahjong.git
cd CMCCmahjong\mahjong-h5
pnpm install
pnpm test
pnpm start
```

浏览器访问 `http://localhost:3000`。手机和电脑在同一网络时，可访问 `http://电脑局域网IP:3000`。

## 目录

- `mahjong-h5/`：H5 客户端、TypeScript 服务端、测试和牌桌素材。
- `docs/GAME_RULES.md`：麻将规则 v0.2 的可追踪源文件。
- `deliverables/`：麻将规则需求规格 Word 固化稿，保留历史版本。
- `scripts/build_mahjong_rules_docx.py`：从规则源文件生成 Word 固化稿。
- `docs/`：项目进度和阿里云部署记录。
- `docs/REFERENCE_NOTES.md`：开源参考项目中采用与明确不采用的麻将逻辑。
- `sources/`：项目同步参考目录。
