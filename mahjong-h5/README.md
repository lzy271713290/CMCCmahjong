# 好友麻将 H5 联机样板

这是麻将项目当前可运行的 H5 客户端与 TypeScript 服务端。已经包含四人联机房间、断线恢复、136张牌、私有手牌、横屏四方牌桌、完整回合、吃碰杠胡、抢杠、特殊杠、连续涨毛，以及服务端权威计分。房主可一键补齐三个测试玩家，方便独自跑通对局。

## 本机运行

```powershell
pnpm install
pnpm test
pnpm start
```

电脑访问 `http://localhost:3000`。同一 Wi-Fi 下，手机访问 `http://电脑局域网IP:3000` 即可一起测试。部署到阿里云时需开放应用端口，正式使用建议配置域名、HTTPS/WSS，并由反向代理转发到本服务。

## 当前边界

- 房间暂存在内存中，服务重启后清空；正式版接入 Redis。
- 当前房间分数仅保存在内存中，服务停止或重启后房间及累计分都会清空。
- 当前完成单局结算，尚未接入下一局、庄家轮转、8/16局模式和整场总结算。
