# 好友麻将 H5 联机样板

这是麻将项目当前可运行的 H5 客户端与 TypeScript 服务端。`audio-mapping-v15` 已达到朋友临时联网可玩版：包含四人联机房间、断线恢复、136张牌、私有手牌、横屏四方牌桌、完整回合、吃碰杠胡、抢杠、两类特殊杠、连续涨毛、服务端权威计分、下一局与庄家轮转、8/16局整场结算、局中解散、操作倒计时、掉线托管、逐局记录、公共操作时间线和可导入的只读动作回放。可用版另含34张牌真人报音、背景音乐、核心牌桌特效、正式计分榜、邀请/战绩分享、再开一桌、规则帮助、操作防重复和弱网重连遮罩。

## 本机运行

```powershell
pnpm install
pnpm test
pnpm start
```

本地服务启动后，可另开终端执行完整四真人整局验收：

```powershell
pnpm run smoke:full-round -- ws://127.0.0.1:3000/ws audio-mapping-v15
```

电脑访问 `http://localhost:3000`。同一 Wi-Fi 下，手机访问 `http://电脑局域网IP:3000` 即可一起测试。部署到阿里云时需开放应用端口，正式使用建议配置域名、HTTPS/WSS，并由反向代理转发到本服务。

## 当前边界

- 房间暂存在内存中，服务重启后清空；正式版接入 Redis。
- 当前房间分数仅保存在内存中，服务停止或重启后房间及累计分都会清空。
- 当前完成跨局累计分、8/16局模式、负分提前结束和同分并列排名；负分暂在每局完整结算后检查。
- 提前结算申请暂按每局结束后的结算页开放；任一玩家发起、其他三人一致同意后结束整场，等待规则 P014 对局中申请时点的最终确认。
- 服务端仍是内存房间；客户端可以恢复网络短暂中断，但服务进程重启后只能安全返回大厅，不能恢复旧牌局。
- 规则引擎和计分保持服务端裁决，客户端只提交操作意图并展示结果。
- 公共操作时间线在内存中最多保留最近200条，JSON导出不包含手牌、玩家令牌或暗杠具体牌面；大厅可导入不超过1MB的 `cmccmahjong-public-replay-v1` 文件进行只读动作回看，服务重启后在线房间与内存时间线仍会清空。
