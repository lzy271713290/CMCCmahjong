# 好友麻将 H5 联机样板

这是麻将项目当前可运行的 H5 客户端与 TypeScript 服务端。已经包含四人联机房间、断线恢复、136张牌、私有手牌、横屏四方牌桌、完整回合、吃碰杠胡、抢杠、特殊杠、连续涨毛、服务端权威计分、下一局与庄家轮转、8/16局整场结算、提前结算投票和逐局记录。房主可一键补齐三个测试玩家，方便独自跑通对局。

## 本机运行

```powershell
pnpm install
pnpm test
pnpm start
```

电脑访问 `http://localhost:3000`。同一 Wi-Fi 下，手机访问 `http://电脑局域网IP:3000` 即可一起测试。部署到阿里云时需开放应用端口，正式使用建议配置域名、HTTPS/WSS，并由反向代理转发到本服务。

## 当前边界

- 房间暂存在内存中，服务重启后清空；正式版接入 Redis。
- 当前房间分数仅保存在内存中，服务停止或重启后房间及累计分都会清空。
- 当前完成跨局累计分、8/16局模式、负分提前结束和同分并列排名；负分暂在每局完整结算后检查。
- 提前结算申请暂按每局结束后的结算页开放；任一玩家发起、其他三人一致同意后结束整场，等待规则 P014 对局中申请时点的最终确认。
- 规则引擎和计分保持服务端裁决，客户端只提交操作意图并展示结果。
