# 好友麻将 H5 联机样板

这是麻将项目的第一段可运行代码，目标是先验证手机浏览器联机和最小牌局流程。当前包含：六位房间号、最多四人、房间状态实时同步、准备状态、刷新或短暂掉线后恢复原座位，以及136张牌、洗牌、随机庄家、私有起手牌、最小牌桌和庄家首次出牌。房主还可一键补齐三个测试玩家，方便独自完成开局验证。

## 本机运行

```powershell
pnpm install
pnpm test
pnpm start
```

电脑访问 `http://localhost:3000`。同一 Wi-Fi 下，手机访问 `http://电脑局域网IP:3000` 即可一起测试。部署到阿里云时需开放应用端口，正式使用建议配置域名、HTTPS/WSS，并由反向代理转发到本服务。

## 当前边界

- 房间暂存在内存中，服务重启后清空；正式版接入 Redis。
- 当前已验证联机大厅、私有发牌和庄家首次出牌；弃牌后暂时停在响应等待阶段，尚未接入过、吃、碰、杠、胡和下一家摸牌。
- 后续规则引擎保持服务端裁决，客户端只提交操作意图并展示结果。

## 下一步规则接入顺序

1. 建立弃牌响应窗口与“过”操作，全部放弃后由下家摸牌。
2. 完成摸牌、出牌循环和操作优先级。
3. 吃、碰、杠、涨毛及补牌。
4. 普通胡、七小对及胡牌合法性。
5. 胡牌倍数、杠分、庄家与整场结算。
6. 操作日志、回放、托管与断线恢复。
