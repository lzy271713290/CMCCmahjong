# 好友麻将 H5 联机样板

这是麻将项目当前可运行的 H5 客户端与 TypeScript 服务端。`persist-control-v17` 包含四人联机房间、断线恢复、136张牌、私有手牌、横屏四方牌桌、完整回合、吃碰杠胡、抢杠、两类特殊杠、连续涨毛、服务端权威计分、下一局与庄家轮转、8/16局整场结算、局中解散、操作倒计时、掉线托管、逐局记录、公共操作时间线和可导入的只读动作回放。v17 另含 Redis 房间持久化、PM2/systemd 进程守护配置、后台公告与强制解散、34张牌真人报音、女声/男声切换、背景音乐、粒子结算特效、正式计分榜、邀请/战绩分享、再开一桌、规则帮助、操作防重复、弱网重连遮罩和后台监控。

## 本机运行

```powershell
pnpm install
pnpm test
pnpm start
```

本地服务启动后，可另开终端执行完整四真人整局验收：

```powershell
pnpm run smoke:full-round -- ws://127.0.0.1:3000/ws persist-control-v17
```

后台管理默认关闭；设置 `ADMIN_TOKEN` 后启动，再运行后台冒烟：

```powershell
$env:ADMIN_TOKEN="你的后台令牌"
pnpm start
pnpm run smoke:admin -- http://127.0.0.1:3000 你的后台令牌 persist-control-v17
```

电脑访问 `http://localhost:3000`。同一 Wi-Fi 下，手机访问 `http://电脑局域网IP:3000` 即可一起测试。部署到阿里云时需开放应用端口，正式使用建议配置域名、HTTPS/WSS，并由反向代理转发到本服务。

## 当前边界

- 配置 `REDIS_URL` 后房间每 2 秒写入 Redis，服务进程重启会自动恢复；未配置时保持纯内存。
- 已完成跨局累计分、8/16局模式、负分提前结束和同分并列排名；负分暂在每局完整结算后检查。
- 提前结算申请按局中/局末开放；任一玩家发起、其他三人一致同意后结束整场。
- 客户端可以恢复网络短暂中断；启用 Redis 后服务进程重启也能恢复旧牌局，未启用时只能安全返回大厅。
- 规则引擎和计分保持服务端裁决，客户端只提交操作意图并展示结果。
- 公共操作时间线在内存中最多保留最近200条，JSON导出不包含手牌、玩家令牌或暗杠具体牌面；大厅可导入不超过1MB的 `cmccmahjong-public-replay-v1` 文件进行只读动作回看，服务重启后在线房间与内存时间线仍会清空。
