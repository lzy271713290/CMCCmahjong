# CMCC 好友麻将项目进度

更新时间：2026-08-14

## 当前目标

先完成手机 H5 四人联机麻将，部署到阿里云供朋友通过手机浏览器访问。完成真实联机验证后，再实现正式牌桌、发牌、回合与吃碰杠胡。

## 开发与交付约定

- 每完成一个可验收里程碑，必须执行测试、更新本进度文档、提交并推送 GitHub。
- 推送完成后，明确通知可以在阿里云拉取和重启，并附上可直接执行的命令。
- 优先使用阿里云公网链接验证；仓库没有保存链接或无法直接测试时，请用户代测，并根据 `logs/server.jsonl` 中的结构化日志继续修正。

## 已完成

- GitHub 仓库：<https://github.com/lzy271713290/CMCCmahjong>

## 当前限制

- 目前只完成最小发牌模型验证；具体手牌尚未下发给客户端，也还没有摸牌、出牌、吃碰杠胡。
- 测试玩家只用于占座和自动准备，不会自动打牌。
- 房间数据只保存在内存中，服务停止或重启后房间会清空。
- 尚未配置进程守护，Workbench/SSH 断开后前台服务可能停止。
- 尚未配置域名、Nginx、HTTPS/WSS。
- TCP 3000 当前属于临时测试端口，不建议长期直接暴露公网。

## 下一阶段建议顺序

1. 验证手机网络异常断开（WebSocket `1006`）后，使用本地令牌自动重连并恢复原座位。
2. 为真实四人联机和断线重连补充回归测试，继续保留结构化日志用于排查。
3. 将玩家自己的起手牌安全下发到客户端，其他玩家只公开手牌数量。
4. 实现回合状态机、摸牌和出牌。
5. 实现吃、碰、杠、涨毛与操作优先级。
6. 实现普通胡、七小对、胡牌倍数和整场结算。
7. 接入牌桌美术图集和动画。
8. 使用 PM2 或 systemd 后台运行，并配置 Nginx、域名和 HTTPS/WSS。
