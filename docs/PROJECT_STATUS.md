## 当前限制

- 目前只是联机大厅和“对局开始”状态，还没有真正发牌、摸牌、出牌、吃碰杠胡。
- 测试玩家只用于占座和自动准备，不会自动打牌。
- 房间数据只保存在内存中，服务停止或重启后房间会清空。
- 尚未配置进程守护，Workbench/SSH 断开后前台服务可能停止。
- 尚未配置域名、Nginx、HTTPS/WSS。
- TCP 3000 当前属于临时测试端口，不建议长期直接暴露公网。

## 下一阶段建议顺序

1. 验证手机网络异常断开（WebSocket `1006`）后，使用本地令牌自动重连并恢复原座位。
2. 为真实四人联机和断线重连补充回归测试，继续保留结构化日志用于排查。
3. 接入牌墙、洗牌、庄家和发牌。
4. 实现回合状态机、摸牌和出牌。
5. 实现吃、碰、杠、涨毛与操作优先级。
6. 实现普通胡、七小对、胡牌倍数和整场结算。
7. 接入牌桌美术图集和动画。
8. 使用 PM2 或 systemd 后台运行，并配置 Nginx、域名和 HTTPS/WSS。
