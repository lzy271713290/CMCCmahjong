# CMCC 好友麻将项目进度

更新时间：2026-08-14

## 当前目标

先完成手机 H5 四人联机麻将，部署到阿里云供朋友通过手机浏览器访问。完成真实联机验证后，再实现正式牌桌、发牌、回合与吃碰杠胡。

## 已完成

- GitHub 仓库：<https://github.com/lzy271713290/CMCCmahjong>
- H5 移动端大厅，可以创建六位数房间、加入房间并显示四个座位。
- WebSocket 服务端统一维护房间状态。
- 玩家准备状态实时同步。
- 刷新或短暂掉线后，使用本地令牌恢复原座位。
- 房主可一键补齐三个测试玩家，方便单人检查四人房间。
- 四人全部准备后，房主可以开始测试对局。
- 六项自动测试全部通过：四人加入、房间满员、掉线恢复、补齐测试玩家、允许开始、未准备禁止开始。
- 已完成手机尺寸界面检查和真实双客户端 WebSocket 冒烟测试。
- 已将幼麟四川麻将的牌桌背景、麻将牌图集、碰杠胡按钮和方向盘图集整理到项目素材目录。
- 已完成《麻将小程序游戏规则需求规格 v0.1》文档，保存在 `deliverables/`。
- 阿里云服务器已能通过公网 IP 的 3000 端口用手机访问。

## 当前限制

- 目前只是联机大厅和“对局开始”状态，还没有真正发牌、摸牌、出牌、吃碰杠胡。
- 测试玩家只用于占座和自动准备，不会自动打牌。
- 房间数据只保存在内存中，服务停止或重启后房间会清空。
- 尚未配置进程守护，Workbench/SSH 断开后前台服务可能停止。
- 尚未配置域名、Nginx、HTTPS/WSS。
- TCP 3000 当前属于临时测试端口，不建议长期直接暴露公网。

## 下一阶段建议顺序

1. 使用四台手机或四个独立浏览器实际验证创建房间、加入、准备、掉线重连。
2. 记录联机过程中出现的问题并修复。
3. 接入牌墙、洗牌、庄家和发牌。
4. 实现回合状态机、摸牌和出牌。
5. 实现吃、碰、杠、涨毛与操作优先级。
6. 实现普通胡、七小对、胡牌倍数和整场结算。
7. 接入牌桌美术图集和动画。
8. 使用 PM2 或 systemd 后台运行，并配置 Nginx、域名和 HTTPS/WSS。
