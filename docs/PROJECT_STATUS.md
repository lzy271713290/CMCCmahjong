# CMCC 好友麻将项目进度

更新时间：2026-08-17

## 当前目标

先完成手机 H5 四人联机麻将，部署到阿里云供朋友通过手机浏览器访问。当前规则、四人联机、横屏牌桌、跨局整场、局中解散、操作倒计时、掉线托管、真人语音与牌桌特效、正式结算、房间恢复能力、弱网重连、公共操作记录、只读动作回放、后台监控、Redis 房间持久化、进程守护、男女声与粒子特效、观战座位、头像聊天表情、丢拖鞋动画、开局分与结算矩阵、三不烙与中发白胡牌规则均已收口为 `ui-voice-v18`。

当前估算：朋友临时联网可玩版代码完成度 **100%**，长期稳定运营版约 **82%**，综合项目约 **90%**。Redis 持久化、进程守护、后台管控、观战与头像聊天特效均已纳入本版；域名 HTTPS、完整牌桌持久化回放、告警与性能趋势仍属于后续长期运营升级。

## 开发与交付约定

- 每完成一个可验收里程碑，必须执行测试、更新本进度文档、提交并推送 GitHub。
- 推送完成后，明确通知可以在阿里云拉取和重启，并附上可直接执行的命令。
- 优先使用阿里云公网链接验证；仓库没有保存链接或无法直接测试时，请用户代测，并根据 `logs/server.jsonl` 中的结构化日志继续修正。
