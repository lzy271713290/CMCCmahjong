# CMCC 好友麻将项目进度

更新时间：2026-08-14

## 当前目标

先完成手机 H5 四人联机麻将，部署到阿里云供朋友通过手机浏览器访问。当前横屏牌桌、弃牌响应候选、过/吃/碰/明杠/点炮胡和服务端优先级裁决已经可本地验收，下一阶段实现玩家自摸阶段操作和结算。

## 开发与交付约定

- 每完成一个可验收里程碑，必须执行测试、更新本进度文档、提交并推送 GitHub。
- 推送完成后，明确通知可以在阿里云拉取和重启，并附上可直接执行的命令。
- 优先使用阿里云公网链接验证；仓库没有保存链接或无法直接测试时，请用户代测，并根据 `logs/server.jsonl` 中的结构化日志继续修正。

## 当前限制

- 当前仅实现针对他家弃牌的吃、碰、明杠和点炮胡；尚未实现当前玩家摸牌后的自摸胡、暗杠、加杠、特殊杠与涨毛。
- 点炮胡目前只生成本局结束结果，尚未实现胡牌倍数、杠分、支付明细、累计总分和下一局庄家轮转。
- 抢杠胡、普通加杠和特殊杠尚未进入响应状态机。
- 测试玩家目前采用“摸到什么就自动打出什么”的最小策略，不具备牌型判断。
- 横屏牌桌已可操作，但尚未加入发牌/摸牌动画、操作按钮、音效和结算画面。
- 房间数据只保存在内存中，服务停止或重启后房间会清空。
- 尚未配置进程守护，Workbench/SSH 断开后前台服务可能停止。
- 尚未配置域名、Nginx、HTTPS/WSS。
- TCP 3000 当前属于临时测试端口，不建议长期直接暴露公网。

## 下一阶段建议顺序

1. 实现当前玩家摸牌后的自摸胡和暗杠候选、操作按钮与杠尾补牌。
2. 实现普通加杠、抢杠胡，以及中发白/东南西北特殊杠和连续涨毛。
3. 实现胡牌倍数、杠分、支付明细、累计总分和下一局庄家轮转。
4. 补充发牌、摸牌、吃碰杠胡动画、音效和正式结算画面。
5. 验证手机网络异常断开（WebSocket `1006`）后的自动恢复，并继续扩展真人联机回归测试。
6. 使用 PM2 或 systemd 后台运行，并配置 Nginx、域名和 HTTPS/WSS。
