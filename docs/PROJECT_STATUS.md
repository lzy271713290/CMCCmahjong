# CMCC 好友麻将项目进度

更新时间：2026-08-15

## 当前目标

先完成手机 H5 四人联机麻将，部署到阿里云供朋友通过手机浏览器访问。当前规则、四人联机、横屏牌桌、跨局整场、提前结算、公开动作反馈、基础音效、正式结算与弱网恢复已经达到朋友测试所需的基本可用版本。

当前估算：朋友临时联网可玩版约 **85%**，长期稳定运营版约 **55%**，综合项目约 **75%**。剩余工作主要集中在四台真机完整局验收、持久化和正式部署，不再是基础牌局主流程缺失。

## 开发与交付约定

- 每完成一个可验收里程碑，必须执行测试、更新本进度文档、提交并推送 GitHub。
- 推送完成后，明确通知可以在阿里云拉取和重启，并附上可直接执行的命令。
- 优先使用阿里云公网链接验证；仓库没有保存链接或无法直接测试时，请用户代测，并根据 `logs/server.jsonl` 中的结构化日志继续修正。

## 当前限制

- 当前已实现普通明杠、暗杠、加杠、中发白/东南西北特殊杠与连续涨毛。
- 胡牌倍数、杠分、支付明细、累计总分、下一局、庄家轮转、8/16局模式、负分提前结束、提前结算投票与最终排名已经实现。
- 加杠、首次特殊杠和每次涨毛都已进入统一抢杠响应状态机。
- 测试玩家目前采用“摸到什么就自动打出什么”的最小策略，不具备牌型判断。
- 当前音效为轻量合成提示音，尚未接入真人语音报牌、背景音乐和完整美术特效。
- 房间数据只保存在内存中，服务停止或重启后房间会清空。
- 尚未配置进程守护，Workbench/SSH 断开后前台服务可能停止。
- 尚未配置域名、Nginx、HTTPS/WSS。
- TCP 3000 当前属于临时测试端口，不建议长期直接暴露公网。

## 下一阶段建议顺序

1. 组织四台真实手机完整打完至少一局，修正机型、浏览器与具体规则差异。
2. 将逐局记录扩展为服务端持久化的公共操作回放，并接入真人语音、背景音乐和更完整的牌面特效。
3. 接入 Redis 保存房间/牌局状态，避免服务重启清空正在进行的牌局。
4. 使用 PM2 或 systemd 后台运行，并配置 Nginx、域名和 HTTPS/WSS。
