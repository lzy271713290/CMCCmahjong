# 幼麟四川麻将逻辑参考记录

参考仓库：<https://github.com/babykylin/babykylin_scmj>

本项目将参考仓库作为只读设计样本，不直接复制四川麻将玩法。实际实现始终以 `docs/GAME_RULES.md` 中已经确认的本地规则为准。

## 已采用的通用设计

- 服务端保存权威牌局状态，客户端只提交操作意图。
- 开局时每名玩家只收到自己的具体手牌，公共广播只包含座位、手牌数量和牌桌公共信息。
- 重连时按玩家身份恢复其个人手牌，不把其他玩家手牌放入同步数据。
- 出牌必须由服务端校验当前轮次、操作阶段和玩家是否真实持有该牌。
- 成功弃牌作为公共信息广播，并在服务端进入独立响应阶段，为后续操作优先级留出边界。

## 明确不采用的内容

- 参考项目使用108张四川麻将牌，本项目使用万、筒、条和七种字牌共136张。
- 参考项目不包含“吃”，本项目必须实现下家吃牌。
- 不采用参考项目的换三张、定缺、血战到底和四川番型结算。
- 不采用其 `Math.random` 洗牌；本项目使用加密随机数驱动的 Fisher–Yates 洗牌。
- 不直接迁移旧 Socket.IO 协议、数据库结构和客户端 Cocos 组件。

## 后续可继续参考的边界

- 弃牌后的候选操作计算与服务端操作标记。
- 胡、杠、碰的等待与优先级裁决框架。
- 操作记录、牌局回放和结算快照的分层方式。

这些边界只参考状态机拆分思路；吃碰杠胡条件、过胡规则、特殊杠与涨毛、计分和整场结算均按本项目规则重新实现并测试。
